# Coreia do Sul 2026

Guia de bolso da viagem à Coreia do Sul (29 de maio a 12 de junho de 2026): Seul, Busan, Suwon e DMZ. Feito para telemóvel.

O conteúdo está em `data.js`: para mudar um local, basta editar esse ficheiro. Os restaurantes estão no objeto `R`, no início, e aparecem no dia em que ficam perto e no separador "Comer". Cada push para `main` publica o site no GitHub Pages.
